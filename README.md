# andromedarabbit's Homebrew Tap

Personal tap for formulae that don't meet homebrew/core notability requirements.

## Installation

```bash
brew tap andromedarabbit/tap
```

## Available Formulae

### kroki
Create diagrams from textual descriptions from kroki.io.

## Usage

After tapping:
```bash
brew install kroki
brew install cliproxyapi-plus
```
